# 💖 Romantic & Creative Coding Collection

Selamat datang di repository kumpulan project coding kreatif dan romantis! 🚀✨

Repository ini berisi berbagai macam kode (terutama dalam bahasa Python dan HTML/CSS/JS) yang berfokus pada seni visual, animasi interaktif, dan teks tersinkronisasi. Semua project di sini dirancang dengan tema kasih sayang, *confession*, hari Valentine, hingga seni lirik lagu.

## 📁 Kategori Project

### 1. 🌐 Web & Interactive Confessions (`HTML / CSS / JS`)
Folder-folder seperti `confess2`, `valentine`, `valentine3`, `love*` (love3, love4, ..., love36), `koiiro kobo`, dll., berisi project berbasis web:
- Halaman web interaktif untuk *confess* atau menyatakan perasaan.
- Animasi love (termasuk 3D love animations).
- Background music dan animasi partikel (canvas) yang romantis.
- **Cara menjalankan:** Buka file `index.html` di dalam masing-masing folder menggunakan web browser.

### 2. 🌺 Python Turtle Animations
Kumpulan script Python yang menggunakan library `turtle` untuk menggambar seni geometri yang indah dan estetik:
- **Bunga (Flowers):** Folder `flower`, `flower 2`, dll. Menggambar pola bunga yang kompleks dan warna-warni (menggunakan `colorsys`).
- **Hati (Hearts):** File seperti `heart.py`, `heart_2.py`, `heart_14.py`, dll. Berisi kode untuk membentuk visualisasi love dengan animasi *drawing* perlahan.
- **Cara menjalankan:** Jalankan script di terminal: `python "flower/flower 9.py"` atau `python heart.py`

### 3. 🎵 Python Lyric Synchronizers
Berbagai file Python di *root directory* (seperti `sempurna.py`, `to the bone.py`, `mangu.py`, `wide awake.py`, dll) adalah script *command-line* yang akan mencetak lirik lagu secara dramatis dengan animasi pengetikan (typing effect) dan delay sinkronisasi yang disesuaikan dengan nada dan ritme aslinya!
- **Cara menjalankan:** `python sempurna.py` (contoh). Matikan lampu kamar dan nikmati liriknya! 🎧

### 4. 🎂 Special Occasions
- Folder `happy birthday python`: Berisi script khusus untuk memberikan kejutan / ucapan ulang tahun secara unik melalui baris kode.

## 🛠️ Prasyarat (Prerequisites)
- **Python 3.x** terinstal di perangkat Anda (untuk menjalankan file `.py`).
- **Web Browser** modern seperti Chrome, Firefox, atau Edge (untuk project web).
